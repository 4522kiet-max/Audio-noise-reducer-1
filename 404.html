Q1. What is the mathematical formulation of SVD on an audio signal?
A 1D audio sequence \(x[n]\) is first converted into a 2D time-frequency matrix \(X \in \mathbb{C}^{M \times N}\) via the Short-Time Fourier Transform (STFT). Singular Value Decomposition factors its magnitude matrix into \(S = U \Sigma V^T\), where \(U\) contains orthogonal frequency basis vectors, \(\Sigma\) contains ordered singular values (\(\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_p \ge 0\)), and \(V^T\) contains temporal envelopes across frames.
Q2. Why do large singular values correspond to signal while small ones correspond to noise?
Coherent acoustic signals (voice formants, musical tones) possess strong spectral correlations across frequencies and frames, which concentrate predominantly into the first few singular vectors associated with large singular values \(\sigma_1 \dots \sigma_k\). In contrast, uncorrelated white noise is dispersed uniformly across all basis directions, forming a flat noise floor of small singular values \(\sigma_{k+1} \dots \sigma_p\).
Q3. State the Eckart–Young–Mirsky Theorem and its significance.
The Eckart–Young–Mirsky theorem proves that the truncated matrix \(S_k = \sum_{i=1}^k \sigma_i u_i v_i^T\) is the unique rank-\(k\) matrix that minimizes reconstruction error: \(\min_{\text{rank}(B) \le k} \|S - B\|_F = \|S - S_k\|_F = \sqrt{\sum_{i=k+1}^p \sigma_i^2}\). This mathematically guarantees that zeroing trailing singular values discards noise while minimizing voice distortion.
Q4. How does the system synthesize the audio back to the time domain?
The cleaned low-rank magnitude matrix \(S_k\) is recombined with the original complex phase matrix \(\Phi = \angle X\) to form \(\hat{X} = S_k \odot e^{j \Phi}\). The Inverse Short-Time Fourier Transform (ISTFT) is applied to each frame, and synthesis window Overlap-Add (OLA) normalizes the overlapping sections to output the 1D clean audio wave \(\hat{x}[n]\).
Q5. How does the frontend communicate with the backend?
The frontend communicates with a Python FastAPI server via REST API (POST /api/denoise-svd) sending the audio data, rank \(k\), and window size. When the backend is offline, the frontend seamlessly executes its built-in browser mathematical calculation engine, ensuring guaranteed uptime during live demonstrations.
